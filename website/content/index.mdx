# Tinkle Schema

`tinkle.v1` is the Protobuf contract for the Tinkle messaging API. It is
maintained as the specification-first source of truth in
[tinkle-org/schema](https://github.com/tinkle-org/schema);
the reference on this site is generated from its proto comments.

| | |
| --- | --- |
| **[Schema reference](/schema/reference)** | Every service, RPC method, message and enum, with doc comments, deprecations and reserved definitions. |
| **[Buf Registry](https://buf.build/tinkle-org/schema)** | Go and Rust SDKs generated and published by the Buf Schema Registry on matching `main` pushes and `v*` tags. |
| **[File Transfers](/schema/file-transfers)** | Resumable upload sessions, canonical file IDs, and byte-range downloads through `FilesService`. |
| **[Introduction](/schema/introduction)** | Schema scope, publication, and implementation status. |

## Status

The contract is **pre-release**: intentional restructuring is expected and
carries no external compatibility commitment.

- This reference is generated on every site build from the current `main` tree —
  it may be ahead of the latest published SDKs.
- SDK publication on the Buf Schema Registry is **trunk-based**: `buf-ci.yaml`
  publishes `main` pushes matching its paths with a moving `main` label, and
  `v*` tags publish version labels. Release-please handles versioning and tags.

## How this site is built

```text
tinkle/v1/*.proto + doc comments        spec source of truth
        ↓
buf build (protobuf descriptor set)
        ↓
website/scripts/generate-reference.mjs   generated reference pages
        ↓
content/ (Nextra content directory)
        ↓
tinkle.me/schema/                        served by the main website
```

To change what appears in the reference, edit the `.proto` doc comments; to
change narrative documentation, edit the hand-written pages in
`website/content/`. The pages under `website/content/reference/` are generated
and git-ignored. Runtime transport bindings belong in their implementation
repositories.
